# Plano — заметки для Claude

- Монорепо pnpm: `apps/api` (NestJS + Prisma), `apps/web` (Next 14 + Tailwind), `packages/shared`.
- После правок в `packages/shared/src` пересобрать: `pnpm --filter @plano/shared build`, иначе api/web не увидят изменений.
- Проверка типов: `npx tsc --noEmit -p apps/api` и `npx tsc --noEmit -p apps/web`.
- Миграции: `prisma migrate dev` интерактивный и в неинтерактивной среде не работает. Создавать SQL через
  `prisma migrate diff --from-schema-datasource prisma/schema.prisma --to-schema-datamodel prisma/schema.prisma --script`
  в новую папку `prisma/migrations/<timestamp>_<name>/migration.sql`, затем `prisma migrate deploy`.
- Окружение с нуля: `./scripts/cloud-setup.sh`.
- Права: новые действия добавлять в `PERMISSIONS` (shared), на сервере — `@RequirePermission(...)` + `PermissionGuard`, в вебе — `useCan()`.
- UI: эталон Linear, профиль дизайна — `.ux-profile.md`. Цвета только через токены `apps/web/src/design/tokens.ts` (акцент и меню #2B2F33). Тексты интерфейса на русском, сухой тон.
- Проверять интерфейс в браузере и скриншотами можно.
- В облаке (Claude Code on the web) окружение готовит хук SessionStart из `.claude/settings.json`: он запускает `scripts/cloud-setup.sh`, лог — `/tmp/plano-setup.log`. Если база или зависимости не поднялись, посмотреть лог и запустить скрипт вручную.
- Мультитенантность: сервисы получают `PrismaService` (скоуп по рабочему пространству, `src/prisma/tenant.ts`). Новая модель — добавить в `SCOPE` (и в `PARENTS`, если есть внешние ключи). Создавая запись User/Project/Card/Template/Role, подмешивать `OWN_FIELDS`/`CARD_FIELDS`. `SystemPrismaService` — только для логина, планировщика и подписанных ссылок. После изменений в доступе к данным: `node apps/api/test/isolation.mjs` на запущенном API.
- Тесты: API — `pnpm --filter @plano/api test` (Jest, база `kanban_test` создаётся и очищается сама; `test:cov` — покрытие). Веб — `pnpm --filter @plano/web test` (Vitest + RTL, `test:cov`). E2E — `pnpm --filter @plano/web e2e` (Playwright, свои порты 3200/3201, база `kanban_e2e`, mock-оплата, владелец платформы `owner@e2e.test`). Проверка типов в приложениях: `pnpm exec tsc --noEmit -p .` внутри `apps/api` и `apps/web` (глобальный `npx tsc` новее и ругается на baseUrl).
- Блокировка тарифа, онбординг и скрытая админка `/platform` (`PLATFORM_ADMIN_EMAILS`) описаны в README.
- Локализация (ru/en): все тексты лежат в `packages/shared/src/locales/{ru,en}.json`, в коде — `t("area.key", { param })` из `@plano/shared` (на сервере язык запроса берётся из заголовка `X-Locale`, у писем — язык получателя `User.locale`). Нового текста в коде на русском быть не должно: добавить ключ в оба файла, множественные числа — объектом `{one, few, many, other}` с параметром `count`. Метки-таблицы в shared — через `lazyLabels`. Не называть локальные переменные `t` (затеняют функцию). Проверка: `test/i18n.test.ts` в web (одинаковые ключи и плейсхолдеры, нет неиспользуемых и отсутствующих ключей) и E2E `i18n.spec.ts` (в английском интерфейсе нет кириллицы).
- Стартовый шаблон «Знакомство с Plano» (`apps/api/src/templates/default-template.ts`, ru/en) состоит из карточек-подсказок по началу работы. Типов карточек нет — для классификации служат метки.
- Локальный запуск: `ecosystem.json` (pm2: `plano-db`, `plano-api`, `plano-web`), команды `pnpm local:setup` и `pnpm pm2:start|stop|logs|status`, гайд — `docs/local-setup.md`.
- ИИ-агенты: `apps/api/src/agents/` (провайдеры в `llm/`, запуск в `agent-runner.service.ts`, инструменты в `tools.ts`, ключи шифруются в `secret.ts`). Агент — `User` с `kind=AGENT`: считается в местах, войти не может, а в списках «Сотрудники» не показывается. Триггер — уведомления (`NotificationsService.wakeAgents` → `AgentEvents`). Новый провайдер: адаптер в `llm/`, запись в `AGENT_PROVIDERS` (shared), тест в `test/agents.spec.ts`.
- Публичный сайт (`components/marketing/*`, `app/page.tsx`, `app/en/*`, `app/pricing`): язык задаёт адрес (`/` и `/en`), тексты берутся через `makeTr(locale)` из `lib/marketing.ts` (ключи `mk.*`), а не из `t()`. Превью продукта на лендинге закрепляет язык через `forceLocale`. Цены на английском — доллары (`USD_MONTHLY`). Юридические страницы только на русском.
- ИИ-агенты — тариф Business (`PlanFeature` `agents`, миграция `agents_business`).
- Публичный API, вебхуки, iCal: `api-tokens/` (токен — JWT с `tok`, проверка в `jwt.strategy.ts`), `webhooks/` (`WebhooksService.emit` вызывается из `CardsService`; новое событие — в `WEBHOOK_EVENTS` shared, вызов emit, строка в `mk.apiDocs.event.*` и в тесте `public-api.spec.ts`), `calendar/`. Новый метод, который стоит показать в документации, — в `ENDPOINTS` в `components/marketing/api-docs.tsx` (+ ключ `mk.apiDocs.ep.*`). Горячие клавиши и палитра — `components/command-palette.tsx`: новая клавиша или команда добавляется там и в `SHORTCUTS`.
