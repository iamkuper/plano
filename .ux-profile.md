# UX Profile

Generated by `setup-ui-ux-skills`. All UI/UX skills in this project read this file before changing layout, copy, or interaction.

## Product

Internal kanban for a team that implements amoCRM for clients. The users are integrators and a lead, working in the tool all day. The primary screen is **the project board**: one implementation, its stages, and its cards.

## Aesthetic reference

- **Standard:** Linear
- **Notes:**
  - Light theme, monochrome base, high density, 1px hairline borders.
  - The main work area is white; navigation sits on a quiet neutral surface.
  - Spend boldness in one place only: board stages carry colour, borrowing the amoCRM pipeline vernacular. Everything else stays neutral.

## Banned anti-aesthetics

- Glassmorphism / `backdrop-filter`.
- Gradients on buttons or logos; decorative gradient washes.
- Pastel pill badges around ordinary metadata (dates, keys, counts, names). Metadata is plain secondary text.
- ALL-CAPS tracked-out labels and eyebrows.
- Meta strings joined with middle dots ("A · B · C").
- Tinted near-black (#111, #0B0B0B) standing in for black on fills. Primary buttons use the accent.
- Monospace for small data labels.
- The SaaS card kit: everything in identical rounded cards with the same grey shadow.
- Cartoon empty-state illustrations.
- Icons inside inputs, except search.
- Text below 12px. 12px is meta only.

## Accessibility target

- **Level:** WCAG 2.1 AA
- **Contrast:** ≥ 4.5:1 for text, ≥ 3:1 for borders and UI glyphs that carry meaning.
- **Touch / focus:** visible 2px focus ring on every interactive element; desktop targets ≥ 28px with padding; Escape closes overlays.

## Brand tone and microcopy voice

- **Voice:** Utilitarian & Minimal.
- **Capitalization:** sentence case for UI copy and buttons.
- **Notes:**
  - Russian UI. Verbs name the result: «Создать проект», then the toast «Проект создан».
  - Errors say what happened and what to do, without apologies.

## Icon library

- **Library:** Lucide
- **Package / path:** `lucide-react` (apps/web)
- **Notes:** stroke 1.75 at 16px. No emoji as UI icons.

## Agent rules

1. Read this profile before creating or editing any UI, CSS, or microcopy.
2. Prefer skills by task:
   - new page → `page-patterns` (name the pattern before markup);
   - layout / chrome → `viewports`;
   - forms → `forms`;
   - overlays → `surfaces`;
   - loaders → `loaders`;
   - empty views → `empty-states`;
   - motion → `motion`.
   
   Before finishing UI, run `ux-audit`.
3. Use only the recorded icon library. Do not mix icon sets or use emoji as UI icons.
4. Never introduce items on the banned list.
5. Destructive actions always use an explicit confirmation dialog that names the entity.
