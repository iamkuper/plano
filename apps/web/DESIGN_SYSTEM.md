# Дизайн-система amo kanban

Эталон — Linear, светлая тема. Профиль продукта и список запретов лежат в [`/.ux-profile.md`](../../.ux-profile.md): прочитайте его перед любой правкой интерфейса.

- **Токены:** `src/design/tokens.ts`. Тема Tailwind генерируется из этого файла, руками её не правим.
- **Компоненты:** `src/components/ui.tsx`.

## Принципы

1. **Тихая оболочка, громкие этапы.** Цвет есть только у этапов доски (палитра воронки amoCRM) и у сигналов: просрочено, срочно, ошибка. Всё остальное нейтральное.
2. **Линии вместо теней.** Поверхности отделяются рамкой 1px `border`. Тень `shadow-raised` только у того, что парит: поповеры, панель задачи, диалоги.
3. **Мета — это текст.** Номер, дата, счётчик и тип пишутся обычным серым текстом `text-xs text-ink-faint`, без «пилюль» и без «·» между частями.
4. **Предложения с маленькой буквы.** Никакого капса в подписях и разделах.
5. **Ритм 4/8.** Отступы 4, 8, 12, 16, 20, 24 px.

## Токены

| Токен | Значение | Где |
|---|---|---|
| `bg` / `surface` | `#FFFFFF` | рабочая зона, карточки, поля |
| `surface-soft` | `#F6F6F7` | меню, полосы доски, наведение |
| `surface-sunken` | `#EFEFF1` | активный пункт меню, выбранный сегмент |
| `border` / `border-strong` | `#E6E6E9` / `#D3D4D9` | линии / наведение |
| `ink` / `ink-faint` / `ink-ghost` | `#1B1C1F` / `#6C6E75` / `#8B8D94` | текст / вторичный / мета |
| `accent` | `#4A5BDC` | основная кнопка, ссылки, фокус |
| `success` · `warning` · `danger` | | сигналы |

- **Этапы:** `stageColor(index, count)`. Первый этап серый, последний зелёный, промежуточные идут по палитре.

## Типографика

Шрифт Golos Text, начертания 400 / 500 / 600.

| Класс | Размер | Применение |
|---|---|---|
| `text-xs` | 12 | только мета |
| `text-sm` | 13 | меню, кнопки, поля, подписи |
| `text-base` | 14 | названия карточек, строки таблиц, текст |
| `text-md` | 16 | заголовки диалогов |
| `text-2xl` | 24 | название задачи в панели, числа в KPI |

## Раскладка

- **Меню** шириной 232 px на `surface-soft`. **Рабочая зона** — белый лист с рамкой, отступ 8 px от краёв окна.
- **`PageHeader`** высотой 48 px: путь › название, `meta`, справа действия.
- **Тулбар доски** высотой 48 px: чипы «Все / Сегодня / 7 дней / Просрочено», затем «Фильтр», «Сортировка», активные фильтры с ×, справа счётчик.
- **Доска:** полосы шириной 288 px, сверху линия цвета этапа 3 px. «+» и «⋯» в шапке полосы появляются при наведении. Карточка: номер и исполнители → название → тип, срок, подзадачи, комментарии.
- **Задача** открывается боковой панелью справа (`Sheet`). Слева содержимое, справа колонка свойств «подпись — значение».

## Компоненты

- **Button:** `primary` (акцент) — одно главное действие на экране. `outline` — вторичное, `ghost` — в тулбарах, `danger` — только кнопка подтверждения удаления.
- **IconButton:** `title` обязателен, он же `aria-label`.
- **Field + Input / Select / Textarea / Checkbox:** у полей есть `invalid`, ошибка выводится через `Field error`.
- **Badge:** только статусы (проект, сотрудник), не мета.
- **Segmented:** переключатели видов и фильтров.
- **Оверлеи:** `Popover`, `Menu` / `MenuItem`, `Tooltip`, `Dialog` (короткие формы), `Sheet` (сущность поверх контекста), `ConfirmDialog`.
- **Состояния:** `Skeleton`, `TableSkeleton`, `BoardSkeleton`, `EmptyState`; `toast()` — результат действия.

## Правила поведения (скилы surfaces, defaults)

- **Удаление** всегда через `ConfirmDialog`: заголовок называет сущность («Удалить карточку AMO-12?»), фокус на «Отмена», подтверждающая кнопка красная с глаголом.
- **Правка одного поля** (название, описание) — прямо на месте, без окон и без сдвига соседних элементов.
- **Выпадающие списки** открываются с подставленным значением, если его можно угадать.
