# Запуск Plano локально

Гайд для проверки сервиса на своём компьютере: база, API и сайт поднимаются одной командой через [pm2](https://pm2.keymetrics.io).

## Что нужно

- **Node.js 20+** (лучше 22): <https://nodejs.org>
- **pnpm**: ставится сам через corepack (`corepack enable`), отдельно ничего не нужно.
- **git**
- Docker и установленный Postgres **не нужны**: база запускается встроенная (порт 5433).
- Windows: запускайте всё в WSL (Ubuntu), команды ниже рассчитаны на bash.

Порты: сайт `3100`, API `3101`, база `5433`. Они должны быть свободны.

## Первый запуск

```bash
git clone https://github.com/iamkuper/plano && cd plano
pnpm local:setup     # зависимости, .env, база, миграции, тестовые пользователи
pnpm pm2:start       # база + API + сайт
```

Через минуту откройте <http://localhost:3100>.

`pnpm local:setup` делает:
1. `pnpm install`;
2. создаёт `apps/api/.env` и `apps/web/.env.local` из `*.env.example`, если их ещё нет;
3. запускает базу под pm2 и ждёт, пока она поднимется;
4. применяет миграции и создаёт тестовых пользователей.

Можно запускать повторно, ничего не сломается.

### Вход

Тестовые пользователи создаются из `apps/api/.env` (`TEST_USER_*`), по умолчанию:

| Почта | Пароль |
| --- | --- |
| `designer@test.local` | `test-6bc713bc1545` |
| `designer2@test.local` | `test2-31b432117b` |

Второй пользователь живёт в **другом пространстве**: удобно проверять изоляцию данных. Или создайте своё пространство на странице регистрации (`/register`).

## Ежедневная работа

| Команда | Что делает |
| --- | --- |
| `pnpm pm2:start` | запускает базу, API и сайт |
| `pnpm pm2:status` | показывает, что работает |
| `pnpm pm2:logs` | логи всех трёх процессов (`pnpm pm2:logs plano-api` — только API) |
| `pnpm pm2:restart` | перезапускает всё |
| `pnpm pm2:stop` | останавливает, не удаляя из списка pm2 |
| `pnpm pm2:delete` | останавливает и убирает из pm2 |

Код перезагружается сам (Nest и Next работают в режиме watch). Нужен перезапуск только после правки `.env`.

После правок в `packages/shared/src` (тексты, типы) пересоберите общий пакет: `pnpm --filter @plano/shared build`.

Запуск по частям: `pnpm exec pm2 start ecosystem.json --only plano-db` (или `plano-api`, `plano-web`).

## Языки

Интерфейс на русском и английском. Язык переключается на страницах входа и регистрации (внизу) и в «Профиле»; по умолчанию берётся язык браузера. Тексты лежат в `packages/shared/src/locales/{ru,en}.json`.

## Что можно настроить в `apps/api/.env`

| Переменная | Зачем |
| --- | --- |
| `PLATFORM_ADMIN_EMAILS` | почты, которым открыта скрытая админка владельца `/platform` (остальным 404) |
| `TBANK_TERMINAL_KEY`, `TBANK_PASSWORD` | тестовый терминал Т-Банка. Без них оплата идёт через встроенную заглушку (страница «Тестовая оплата») |
| `API_PUBLIC_URL`, `APP_URL` | публичные адреса для уведомлений банка и ссылок в письмах (локально: `http://localhost:3101` и `http://localhost:3100`) |
| `SMTP_*`, `MAIL_FROM` | почта. Без неё письма (приглашения, сброс пароля) только пишутся в лог API: `pnpm pm2:logs plano-api` |
| `SELLER_*` | реквизиты продавца для счетов в PDF |
| `DISABLE_SCHEDULERS=1` | отключает фоновые задачи (повторяющиеся карточки, напоминания, продления) |

Реальный терминал Т-Банка работает только с доступом в интернет к `securepay.tinkoff.ru`, а банк должен достучаться до вашего `API_PUBLIC_URL` (для уведомлений нужен туннель, например ngrok/cloudflared). Для проверки интерфейса хватает заглушки.

Пароль терминала и другие секреты храните только в `.env`: он в `.gitignore`.

## Проверка тестами

```bash
pnpm --filter @plano/api test     # API (Jest), своя база kanban_test
pnpm --filter @plano/web test     # компоненты (Vitest)
pnpm --filter @plano/web e2e      # браузерные сценарии (Playwright), свои порты 3200/3201
```

Для E2E один раз нужен браузер: `pnpm --filter @plano/web exec playwright install chromium`, затем
`CHROMIUM_PATH="$(cd apps/web && node -e "console.log(require('@playwright/test').chromium.executablePath())")" pnpm --filter @plano/web e2e`.
Базу при этом оставьте запущенной (`pnpm pm2:start`, достаточно процесса `plano-db`).

## Если что-то не так

- **Порт занят.** Найдите процесс: `lsof -i :3100` (или `:3101`, `:5433`) и остановите его. Старая копия pm2: `pnpm pm2:delete`.
- **Сайт открывается, но ничего не грузится.** Проверьте, что API жив: `pnpm pm2:logs plano-api`. Частая причина — база ещё поднимается, подождите минуту, API сам переподключится.
- **«Database does not exist» / ошибки миграций.** Повторите `pnpm local:setup`.
- **Полный сброс данных.** `pnpm pm2:delete`, затем удалите папку `apps/api/.pgdata` и снова `pnpm local:setup`.
- **Поиск по кириллице не различает регистр.** Встроенная база работает с локалью «C». Для продакшена нужна база с UTF-8 локалью.
- **pm2 хочется пережить перезагрузку компьютера.** `pnpm exec pm2 save`, затем `pnpm exec pm2 startup` и выполните показанную команду.
