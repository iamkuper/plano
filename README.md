# amo-kanban

Канбан-доски для команды интеграторов amoCRM (только для нашей компании).

## Стек

- `apps/api`: NestJS + Prisma + PostgreSQL
- `apps/web`: Next.js 14 (App Router) + Tailwind
- `packages/shared`: общие типы и константы

## Запуск

```bash
pnpm install
cp apps/api/.env.example apps/api/.env
pnpm db:up          # локальный Postgres на :5433, Docker не нужен
pnpm db:migrate     # применить схему
pnpm db:seed        # шаблон «Стандартное внедрение amoCRM»
pnpm api:dev        # http://localhost:3101
pnpm web:dev        # http://localhost:3100
```

При первом запуске откройте `/setup` и создайте администратора. Остальных
сотрудников администратор добавляет через `POST /users`.

## Модель

Клиент → Проект (внедрение) → Доска → Колонки → Карточки (чек-лист,
комментарии, учёт времени, история).
Доска команды — сводный вид карточек всех активных проектов, сгруппированных
по названию колонки.
